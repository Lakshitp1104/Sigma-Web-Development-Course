## 🔧 Customization

### Change Dark Theme Colors
1. Open `style.css`
2. Find `:root {`
3. Edit the color values
4. Save - changes apply instantly!

### Change Light Theme Colors
1. Open `style.css`
2. Find `html.light-theme {`
3. Edit the color values
4. Save - changes apply instantly!

### Add New Theme
1. Add CSS class in `style.css`
2. Define color variables
3. Update `applyTheme()` in `script.js`
4. Restart app
