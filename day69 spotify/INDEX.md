## 🚀 Getting Started

### Step 1: Run the App
```bash
# Option A: VS Code Live Server (Recommended)
Right-click index.html → "Open with Live Server"

# Option B: Direct Open
Double-click index.html
```

### Step 2: Add Your Music
```
Create/organize MP3 files:
📁 songs/
├── 📁 album1/
│   └── 📁 songs/
│       ├── song1.mp3
│       ├── song2.mp3
│       └── song3.mp3
├── 📁 album2/
│   └── 📁 songs/
└── 📁 album3/
    └── 📁 songs/
```

### Step 3: Refresh & Enjoy
```
Press F5 or Ctrl+R to refresh your browser
Songs will appear automatically!
```
