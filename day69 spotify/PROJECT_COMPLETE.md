## 🎵 How to Add Music

### Quick Method
1. Find MP3 files
2. Name them: `song1.mp3`, `song2.mp3`, etc.
3. Put in `songs/album1/songs/` folder
4. Refresh browser ✅

### Complete Setup
1. Create album folder: `songs/my-album/`
2. Add `cover.jpg` (album art)
3. Create `info.json`:
```json
{
  "title": "Album Name",
  "artist": "Artist Name",
  "description": "Short description",
  "cover": "cover.jpg"
}
```
4. Create `songs/` subfolder inside
5. Add MP3 files
6. Edit `script.js` line 69 to include your album
7. Refresh browser ✅
